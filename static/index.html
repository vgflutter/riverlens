Collega OpenAI

  1. Copia .env.example in .env nella cartella RiverLens.
  2. Inserisci OPENAI_API_KEY e OPENAI_MODEL. Per gli screenshot scegli un modello con input immagini.
  3. Riavvia l’app e ricarica questa pagina.

La chiave resta nel processo locale. Le richieste AI vengono inviate solo premendo il relativo pulsante e confermando i dati. Usa una chiave API del tuo progetto OpenAI; non le credenziali di accesso a ChatGPT.

Replay, importazione e simulazioni non richiedono alcuna chiave. Le chiamate API possono comportare costi sul tuo progetto OpenAI.
